# КОНВЕЙЕР

Браузерная сюжетная игра-сортировка. Mobile-first (портрет, 360–430px), десктоп — центрированная колонка до 600px.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (доступен и по сети: --host)
npm run build    # проверка типов + production-сборка в dist/
```

Проверить на телефоне: телефон и компьютер в одной сети → открыть `Network`-адрес из вывода `npm run dev`.
В Chrome DevTools: Device Toolbar → Pixel 5 / iPhone SE, портрет.

## Стек

React 18 · Vite · TypeScript · Zustand (+persist, ключ `conveyor-save`) · @dnd-kit/core · framer-motion · CSS Modules.
Вся графика — SVG-компоненты и CSS, частицы фона — canvas. Без внешних ассетов и шрифтов.

## Как устроено

- `src/hooks/useGameLoop.ts` — игровой движок (класс `GameEngine`): requestAnimationFrame, спавн по линиям,
  перегрев, комбо, приказы, призраки/союзники, сюжетные события. Позиции объектов пишутся прямо в
  `style.transform` — React перерисовывается только при спавне/удалении и ~12 раз/с для HUD.
- `src/hooks/useDragObject.ts` — drag-and-drop (PointerSensor, порог 6px отделяет тап от перетаскивания).
- `src/hooks/useBossOrders.ts` — 5 приказов Начальника и их правила.
- `src/data/levels.ts` — 10 уровней (скорость, линии, цели, таймер считается из темпа подачи).
- `src/data/dilemmas.ts` — дилеммы, исходы, флаги сюжета и сцены без выбора.
- `src/data/finales.ts` — 6 концовок и правило выбора концовки; `src/utils/secretPath.ts` — 7 условий секрета.
- `src/store/gameStore.ts` — сохранение (монеты, инструменты, прогресс, ачивки, сюжет, концовки, статистика).

## Управление

- Тап по объекту → тап по контейнеру, или перетащить объект в контейнер.
- Персонажи на ленте открывают дилемму, когда доезжают до середины (или по тапу).
- Вопросы (ур. 10) берутся только под «Сомнением»; тени «???» (ур. 8) трогать нельзя — пропускай.

## Dev-хуки

В режиме `npm run dev` доступны `window.__engine` (текущий движок) и `window.__ui` (UI-стор) — для автотестов.
В production-сборке их нет.
