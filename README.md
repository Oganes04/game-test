# Конвейер

Браузерная сюжетная игра на React, TypeScript и Vite.

## Запуск

Требуется Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite. Для сборки используйте `npm run build`.

## Управление

Коснитесь объекта и выберите контейнер. Объекты также можно перетаскивать мышью или касанием. На клавиатуре выберите объект, затем нажмите 1, 2 или 3. Синие, фиолетовые и красные подписи контейнеров относятся к линиям соответствующего цвета. Escape ставит смену на паузу.

Прогресс, сюжет и текущая смена хранятся в браузере под ключом `conveyor-save`. Пройденную смену можно открыть из журнала и изменить сюжетный выбор. При запуске другой смены активная контрольная точка заменяется. Сброс сохраняет достижения и открытые концовки.

## Исходники

- `src/data` — уровни, диалоги, задания, инструменты, достижения и концовки.
- `src/store` — состояние сохранения и контрольной точки.
- `src/screens` — игровой экран, конвейер, управление и смены.
- `src/components` — CSS-портреты персонажей.
- `src/hooks` — игровой цикл.
- `src/utils` — условия финалов и секретного пути.
- `src/App.tsx` — меню, инструктаж, журнал смен, магазин и архив.

Портреты рисуются CSS. Для движущихся предметов используются системные эмодзи.
